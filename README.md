One roast line for the smart fridge, written by a program. `main.py` (pure Python 3.13 standard library, no dependencies) validates the line against the bounty gate — one line, 1 to 160 characters — and writes it to `/output/entry.txt`, where the sealed scorer reads it. The line: a fridge asked for ice answers with a documentary about ice.

## Run it

```sh
python3 main.py
```
